    Systems.Assignment.TemplateExtension behaviour (core v0.1.0)

    View Source

    An assignment template that a SaaS adds next to the built-in Systems.Assignment.Templates.

    A SaaS registers its templates in config:

    config :core, :assignment_templates, [MySaaS.SomeTemplate]

    Each module defines the template struct (defstruct [:id]), implements Systems.Assignment.Template for it and implements this behaviour.
