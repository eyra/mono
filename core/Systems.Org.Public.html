    add_member(org, user)

    Assigns the :member role to a user for the given organisation. Auth roles are the source of truth for membership (Option C pattern).

    add_user(identifier, user)
    archive(node)

    Archives an organisation node.

    assign_owner(org, user)

    Assigns the :owner role to a user for the given organisation and immediately syncs the AddDomainMembers NextAction so the new owner sees outstanding domain-matched users on their next admin visit without waiting for a registration event.

    auth_module()
    can_manage?(org, user)

    Returns true when the user is allowed to manage the given organisation (members, settings, domain-matched actions). Mirrors the access rule used by the UI: system admins can manage any org; org owners can manage their own.

    clear_domain_match_next_action(org_id, user)

    Clears the AddDomainMembers NextAction for a user on a given org. Used when revoking the :owner role so the action disappears immediately instead of lingering until the next sync pass.

    list_members(org)

    Lists all users with the :member role for the given organisation. Auth roles are the source of truth for membership (Option C pattern).

    list_members_with_added_at(node_model)

    Like list_members/1 but returns {user, added_at} tuples where added_at is the timestamp at which the :member role was granted on the org's auth_node. Used by the Members tab to power the "Recent" filter.

    Checks if the user owns any organisations.

    print_auth_roles(term)

    restore(node)

    Restores an archived organisation node.

    revoke_owner(org, user)

    Revokes the :owner role from a user for the given organisation and clears their AddDomainMembers NextAction for this org, since they are no longer responsible for adding domain-matched members here.

    sync_all_domain_match_next_actions(user)

    Syncs NextActions for a specific user across relevant orgs. For system admins: syncs all orgs. For org owners: syncs only orgs they own. Used as a fallback when opening admin pages.

    sync_domain_match_next_action(node, user, locale \\ :en)

    Syncs the NextAction for domain-matched users. Creates the action if domain-matched users exist, clears it otherwise.

    sync_next_actions_for_new_user(user)

    Syncs NextActions for all org owners when a new user registers. Finds orgs whose domains match the user's email and notifies their owners.
