    Core.Env (core v0.1.0)

    View Source

    The one place that names the OTP application whose config Mica reads.

    Code outside config/ and tests reads and writes application config through this module instead of calling Application.*_env(:core, ...) directly, so renaming the application only changes @app here. The credo check Credo.Check.Warning.CoreEnvAccess enforces this.

    Compile-time reads use the compile_env/2 macro, which keeps the release check that the value did not change between compile time and runtime:

    require Core.Env
@policy_urls Core.Env.compile_env(:policy_urls)
