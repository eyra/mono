# `Frameworks.Pixel.ErrorHelpers`
[🔗](https://github.com/eyra/mono/blob/main/mica/frameworks/pixel/error_helpers.ex#L1)

Conveniences for translating and building error messages.

# `border_color`

Returnes border color in error, focus, and normal state.

# `error_message`

Generates message for inlined form input errors.

# `error_tag`

Generates tag for inlined form input errors.

# `has_error?`

Checkss if there are errors.

# `show_errors?`

Checkss if there are errors.

# `translate_error`

Translates an error message using gettext.
