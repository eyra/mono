# `MicaWeb.UI.ProgressBar`
[🔗](https://github.com/eyra/mono/blob/main/mica/lib/mica_web/ui/progress_bar.ex#L1)

  Progress bar capable of stacking multiple bars.
  The bars will be sorted on size and will be stacked from large to small.

# `progress_bar`

## Attributes

* `size` (`:integer`) - Defaults to `0`.
* `bars` (`:list`) - Defaults to `[]`.
* `bg_color` (`:string`) - Defaults to `"bg-grey4"`.
