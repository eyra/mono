# `Systems.Account.UserNotifier`
[🔗](https://github.com/eyra/mono/blob/main/mica/systems/account/user_notifier.ex#L1)

# `deliver_already_activated_notification`

Deliver instructions to users that are already activated.

# `deliver_confirmation_instructions`

Deliver instructions to confirm account.

# `deliver_otp`

Deliver OTP sign-in code to the given email address.

# `deliver_reset_password_instructions`

Deliver instructions to reset a user password.

# `deliver_update_email_instructions`

Deliver instructions to update a user email.
