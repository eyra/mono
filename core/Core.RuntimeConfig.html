    Core.RuntimeConfig (core v0.1.0)

    View Source

    Building blocks for a SaaS's config/runtime.exs.

    Every helper takes the environment as a map (System.get_env/0 in runtime.exs, a fixture in tests) and returns plain config values. They read each setting under one name only, and environment values choose the setup, never the platform the release runs on.

    mailer(env, opts)

    Mailer options: Mailgun when MAILGUN_API_KEY is set, otherwise Amazon SES (with the keys and region from s3/1).

    Options: :name and :domain of the app, :mail_domain to send from and :mailgun_base_uri.

    repo(env)

    Repo options from DATABASE_URL.

    TLS is on when DB_CA_PATH is set. It verifies the peer unless DB_TLS_VERIFY=verify_none, and takes the server name for SNI and the hostname check from the URL host. ECTO_IPV6=true (or 1) connects over IPv6.
