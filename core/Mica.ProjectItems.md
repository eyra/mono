# `Mica.ProjectItems`
[🔗](https://github.com/eyra/mono/blob/main/mica/lib/mica/project_items.ex#L1)

The project item types of the composition (`c:Mica.System.project_items/0`).

# `all`

The `Mica.ProjectItem` modules, in `c:Mica.SaaS.systems/0` order.

# `fetch!`

The `Mica.ProjectItem` module of a type name. Raises for a name the composition doesn't have.

# `get`

The `Mica.ProjectItem` module of a type name, or `nil`.

# `type_of`

The type name of a target struct or schema, or `nil` for a schema that is no item type.
