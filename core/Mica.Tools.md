# `Mica.Tools`
[🔗](https://github.com/eyra/mono/blob/main/mica/lib/mica/tools.ex#L1)

The tool types of the composition (`c:Mica.System.tools/0`).

# `all`

The `Mica.Tool` modules, in `c:Mica.SaaS.systems/0` order.

# `fetch!`

The `Mica.Tool` module of a type name. Raises for a name the composition doesn't have.

# `get`

The `Mica.Tool` module of a type name, or `nil`.

# `type_of`

The type name of a tool struct or schema, or `nil` for a schema that is no tool.
