    Core.RuntimeConfig.Snapshot (core v0.1.0)

    View Source

    Evaluates a runtime config file against a fixed set of environment variables and renders the result as stable text, so a change in what an environment gets shows up as a diff.

    The process environment is replaced by the fixture for the duration of the evaluation and restored afterwards, so callers must not run concurrently.
