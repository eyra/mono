    Systems.Admin.Panel behaviour (mica v0.1.0)

    A tab on the Admin page (/admin/config), with an embedded live view.

    Systems contribute panels with Mica.System.admin_panels/0; the page shows them in Mica.SaaS.systems/0 order.

    defmodule Systems.Admin.ActionsPanel do
  use Systems.Admin.Panel
  use Gettext, backend: MicaWeb.Gettext

  @impl true
  def id, do: :actions

  @impl true
  def title, do: dgettext("eyra-admin", "actions.title")

  @impl true
  def audience, do: :admin

  @impl true
  def live_view, do: Systems.Admin.ActionsView
end

    The audience says who sees the panel: :admin only system admins, :org_admin also admins of an organisation. System admins see every panel. A panel that is not enabled?/0, for example because its feature flag is off, is shown to nobody.
