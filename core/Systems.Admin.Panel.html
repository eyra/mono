    Systems.Admin.Panel behaviour (core v0.1.0)

    View Source

    A tab on the Admin page (/admin/config), with an embedded live view.

    Systems contribute panels with Core.System.admin_panels/0; the page shows them in Core.SaaS.systems/0 order.

    defmodule Systems.Admin.ActionsPanel do
  use Systems.Admin.Panel
  use Gettext, backend: CoreWeb.Gettext

  @impl true
  def id, do: :actions

  @impl true
  def title, do: dgettext("eyra-admin", "actions.title")

  @impl true
  def audience, do: :admin

  @impl true
  def live_view, do: Systems.Admin.ActionsView
end

    The audience says who sees the panel: :admin only system admins, :org_admin also admins of an organisation. System admins see every panel.
