# `Frameworks.Pixel.Panel`
[🔗](https://github.com/eyra/mono/blob/main/mica/frameworks/pixel/components/panel.ex#L1)

  Grouping information in a card-like fashion.

# `clickable`

## Attributes

* `bg_color` (`:string`) - Defaults to `"bg-grey6"`.
* `size` (`:string`) - Defaults to `"h-full"`.
* `align` (`:string`) - Defaults to `"text-left"`.
* `padding` (`:string`) - Defaults to `"p-6 lg:p-8"`.
* `event` (`:string`) - Defaults to `"handle_panel_click"`.
* `item` (`:string`) (required)
* `target` (`:any`) - Defaults to `false`.
## Slots

* `title` (required)
* `inner_block` (required)

# `flat`

## Attributes

* `bg_color` (`:string`) - Defaults to `"bg-grey6"`.
* `size` (`:string`) - Defaults to `"h-full"`.
* `align` (`:string`) - Defaults to `"text-left"`.
* `padding` (`:string`) - Defaults to `"p-6 lg:p-8"`.
## Slots

* `inner_block` (required)
* `title`

# `usp`

## Attributes

* `title` (`:string`) (required)
* `description` (`:string`) (required)
* `title_color` (`:string`) - Defaults to `"text-grey1"`.
* `description_color` (`:string`) - Defaults to `"text-grey2"`.
