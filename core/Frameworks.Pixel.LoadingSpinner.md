# `Frameworks.Pixel.LoadingSpinner`

# `primary`

## Attributes

* `size` (`:string`) - Defaults to `"w-6 h-6"`.
* `show_loading_text?` (`:boolean`) - Defaults to `false`.
* `loading_text` (`:string`) - Defaults to `"Loading"`.

# `progress_spinner`

## Attributes

* `progress` (`:integer`) - Defaults to `0`.
* `size` (`:integer`) - Defaults to `30`.

# `secondary`

## Attributes

* `size` (`:string`) - Defaults to `"w-6 h-6"`.
* `show_loading_text?` (`:boolean`) - Defaults to `false`.
* `loading_text` (`:string`) - Defaults to `"Loading"`.
