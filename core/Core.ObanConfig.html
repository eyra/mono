    Core.ObanConfig (core v0.1.0)

    View Source

    Builds the Oban config that Core.Application starts, from config :core, Oban, the queues and crons the systems declare (Core.System.oban_queues/0, Core.System.oban_crons/0) and the plugin names config :core, :oban_plugins enables.

    Mica adds its own queues: default and this node's storage delivery queue. The storage delivery queue is named after the node (storage_delivery_local_core@host): data donation files wait on that node's disk, so only that node may run its jobs.

    Plugins run only where their name is enabled (ENABLED_OBAN_PLUGINS in releases, every name in config/dev.exs):

    config :core, :oban_plugins,
  enabled: ["pruner", "lifeline", "advert_expiration"],
  schedule_overrides: [advert_expiration: "*/10 * * * *"]

    A name is one of Mica's plugins (plugins/0) or a system's cron. All enabled crons share one Oban.Plugins.Cron. schedule_overrides replaces the schedule of the crons it names.

    Summary

    Functions

    config(config, declared)

    config with Mica's queues and the declared queues. A queue that config lists keeps the limit set there; queues: false (tests) keeps every queue off. Raises when a system declares one of Mica's queues.

    plugins()

    Mica's own plugins, by name.

    put_plugins(config, crons, oban_plugins)

    config with the plugins and crons that oban_plugins (config :core, :oban_plugins) enables added to the plugins config lists, Mica's plugins first, then one Oban.Plugins.Cron with the enabled crons in their order. plugins: false (tests) keeps every plugin off. Raises when a system declares a cron with the name of one of Mica's plugins.

    queues(node \\ Node.self())

    Mica's own queues on node.

    unknown_plugins(crons, oban_plugins)

    The names oban_plugins enables that are neither Mica's plugins nor one of crons.
