# `MicaWeb.Layouts.Workspace.Composer`
[🔗](https://github.com/eyra/mono/blob/main/mica/lib/mica_web/controllers/layouts/workspace/composer.ex#L1)

Workspace layout composer for LiveView pages.

Supports two modes:
- Default (Fabric): Uses Fabric.LiveHook for legacy component support
- LiveNest: Pure LiveNest setup, assumes MicaWeb.routed_live_view is used
