# `Next.Systems.Announcement.Private`
[🔗](https://github.com/eyra/mono/blob/main/next/systems/announcement/_private.ex#L1)

# `compose_path`

The path of the page to compose a new announcement (`:new`) or to open one, a
plain path like `page_path/1`.

# `kind_label`

# `list_path`

The full list of published announcements addressed to the signed-in user.

# `page_path`

The path of the announcement page (`Next.Systems.Announcement.Routes`). A plain
path, not `~p`: other SaaS builds compile this system without its routes.

# `page_url`

The full address of the announcement page, for use outside Next such as in email.

# `priority_label`

# `published_date`

The publication date in `timezone` and the current locale, such as "28 October 2026".
