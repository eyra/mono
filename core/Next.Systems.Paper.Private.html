    check_paper_exists(arg1, paper_set)

    Centralized function to check if a paper exists in the database. Returns {:existing, paper} if found, :new if not found.

    Logic:

    • If paper has a DOI: check only by DOI (different DOIs = different papers)
    • If paper has no DOI: check by title
