# `Mica.Directors`
[🔗](https://github.com/eyra/mono/blob/main/mica/lib/mica/directors.ex#L1)

The directors of the composition (`c:Mica.System.directors/0`).

# `all`

Director name to module.

# `fetch!`

The module of a director name. Raises for a name the composition doesn't have.

# `get`

The module of a director name (atom or string), or `nil`.
